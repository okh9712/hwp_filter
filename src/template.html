HWP 문항 필터

HWP 파일을 올리고 남길 문항 번호를 고르면, 나머지 문항을 삭제한 새 HWP 파일을 만들어 줍니다. 모든 처리는 이 브라우저 안에서만 이루어지며 파일이 외부로 전송되지 않습니다.

1HWP 파일 올리기

여기로 파일을 끌어다 놓거나 클릭해서 선택
.hwp (한글 5.x 형식)

2남길 문항 번호 선택

문항 번호 (괄호 안은 해당 번호의 문항 수)
번호 없는 구분

3실행

PDF는 남긴 문항의 텍스트만 A4 2단으로 정리해 인쇄 창을 엽니다. 대상을 “PDF로 저장”으로 선택하세요. 그림·표·수식은 “[그림/표 생략]”으로 표시되며 원본 서식은 재현되지 않습니다. 원본 그대로의 PDF가 필요하면 저장된 HWP를 한글에서 열어 PDF로 저장하세요.
미리보기 (남기는 문항 · 선택 변경 시 자동 갱신)
번호를 선택하면 여기에 결과가 표시됩니다.
텍스트 기준 미리보기입니다. 그림·표·수식은 “[그림/표 생략]”으로 표시되며, 실제 HWP에는 원본 그대로 남습니다.
문항 목록 확인 (태그가 어떻게 인식됐는지 점검)
상태구분문항 수첫 문단

인식 규칙: 발문 끝의 [25년 10월 19번] 같은 태그를 기준으로 문항을 나눕니다. 태그가 없는 윗글의 … 같은 후속 문항은 바로 앞 문항(묶음 지문)과 함께 남기거나 삭제됩니다. 41~42번처럼 여러 번호가 묶인 문항은 그중 하나만 선택해도 남습니다.
